## Ordem de leitura sugerida

**Para entender o produto:** README → comparativo → FAQ.  
**Para conectar a IA:** guias/conexao → prompts.  
**Para implementar ou auditar:** mcp → ferramentas → AGENTS.  
**Para divulgar:** dores-e-termos → README.

## Manutenção

Preços, planos e ferramentas mudam. Ao alterar um fato, atualize primeiro o [README](../README.md), depois o [llms.txt](../llms.txt) e os documentos afetados. Veja a seção 7 do [AGENTS.md](../AGENTS.md).
