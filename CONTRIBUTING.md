# Contribuindo

Obrigado pelo interesse. Este repositório é a documentação pública do Donnar e do seu servidor MCP. O foco é **precisão, clareza e utilidade** — não volume.

## O que aceitamos

- Correções de fatos, links quebrados e erros de português.
- Exemplos de prompts que funcionam de verdade com o MCP.
- Configurações de novos clientes MCP (VS Code, Zed, Cline, Continue etc.).
- Melhorias na documentação de OAuth, permissões, privacidade e limites.
- Relatos de uso que ajudem a explicar uma dor real (sem dados pessoais).

## O que não aceitamos

- Dados reais de igrejas, voluntários, visitantes ou inscritos.
- Credenciais, tokens, chaves ou capturas de tela com dados sensíveis.
- Conteúdo difamatório sobre concorrentes.
- Promessas de preço, prazo, desconto ou recurso que não exista.
- Spam, links afiliados ou conteúdo sem relação com o produto.

## Como contribuir

1. Abra uma issue descrevendo o problema ou a sugestão.
2. Para mudanças maiores, aguarde o retorno antes de abrir o pull request.
3. Faça o fork, crie uma branch descritiva e envie o PR.
4. Descreva o que mudou e por quê. Inclua a fonte do fato (página oficial, código ou teste).

## Regras de conteúdo

- Escreva em **português do Brasil**, com tom direto e sem jargão desnecessário.
- Use os links canônicos: `https://donnar.app`, `https://dash.donnar.app`, `https://mcp.donnar.app/start`.
- Preços e limites devem bater com https://donnar.app/#planos.
- Nomes de ferramentas e campos devem bater com [docs/ferramentas.md](docs/ferramentas.md).
- Regras de acesso e privacidade devem bater com [docs/mcp.md](docs/mcp.md).
- Não duplique textos longos: aponte para o documento dono do assunto.

## Checklist do pull request

- [ ] O texto está em português e sem erros evidentes.
- [ ] Os links abrem e apontam para páginas oficiais.
- [ ] Preços, planos e limites estão corretos.
- [ ] Nenhum dado pessoal, token ou segredo foi incluído.
- [ ] Exemplos de MCP usam `https://mcp.donnar.app/start`.
- [ ] A mudança foi refletida no `README.md`, `llms.txt` ou `AGENTS.md` quando necessário.
